# How to Import Agency OS into Notion

You can easily import the `Agency_OS.md` file into your Notion workspace to get the template structure.

## Steps

1.  **Download the File**: Ensure you have the `Agency_OS.md` file saved on your computer.
2.  **Open Notion**: Go to your Notion workspace (web or desktop app).
3.  **Click Import**: In the left-hand sidebar, towards the bottom, click on **Import**.
4.  **Select Format**: In the import dialog, choose **Text & Markdown**.
5.  **Choose File**: Browse and select the `Agency_OS.md` file you downloaded.
6.  **Done**: Notion will create a new page named "Agency OS" with the content, including the Team table and section headers.
